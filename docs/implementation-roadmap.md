Playback currently uses Desktop/PipeWire with selectable ReplayGain (default Auto), using the documented initial FLAC metadata path. Explicit direct ALSA output is implemented with strict submission gates; final PCM/device qualification remains unverified. Development checks use fictional data and synthetic audio; real music stays stopped unless explicitly started by the user.
