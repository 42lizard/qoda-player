These implementation tickets turn them into reviewable increments; the [consolidated specification](first-release-specification.md) and [accepted support boundary](first-release-scope-proposal.md) distinguish implemented software from remaining owned-server qualification in #16.

Playback currently uses Desktop/PipeWire with selectable ReplayGain (default Auto), using the documented embedded metadata paths. Explicit direct ALSA output is implemented with strict submission gates; final PCM/device qualification remains unverified. Development checks use fictional data and synthetic audio; real music stays stopped unless explicitly started by the user.
