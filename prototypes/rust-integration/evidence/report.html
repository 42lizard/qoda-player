What this establishes

The measured local transport, bounded QML model, authenticated mock artwork, libmpv ownership/event path and minimal backend MPRIS controls work together. UI failure/restart leaves the backend alive; a backend restart creates a new instance and starts paused.

What remains unverified

  • Synthetic loopback HTTP only; no Plex or TLS qualification
  • Null audio only; no fidelity or gapless claim
  • No durable queue/checkpoint implementation; crash fixture starts empty and paused
  • Minimal MPRIS subset only; no full compliance claim
  • IPC controls, not physical keyboard acceptance
  • One local run; sampled RSS double counts shared mappings and is not a leak proof

The stock Quickshell portal-registration warning remains captured in the startup log. This artifact does not resolve product desktop identity. Operation-token caching is bounded and in-memory; uncertain mutations must be reconciled, never blindly replayed.
